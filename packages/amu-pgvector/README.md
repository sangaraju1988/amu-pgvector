# amu-pgvector

Python client for [amu-pgvector](https://github.com/sangaraju1988/amu-pgvector) — see the repository root README for the full quickstart, security model, and benchmarks.

The `[mcp]` extra (`pip install amu-pgvector[mcp]`) adds an `amu-pgvector-mcp` console script: an MCP server exposing `amu_search`, `amu_record` and `amu_check_conflict` as lineage-gated tools. See `submissions/mcp-registry.md` in the repository for registry publishing details.
